# AWS Core Infrastructure, Purple Teaming & Detection Engineering CTF Labs

Welcome to the **AWS Core Infrastructure, Purple Teaming & Detection Engineering CTF Lab Collection**. This repository provides an organized, searchable catalog of practical cybersecurity labs and Capture The Flag (CTF) challenges hosted on Learn SecByte.

This collection bridges foundational cloud engineering on **Amazon Web Services (AWS)** with advanced collaborative security disciplines, including Threat-Informed Defense, Endpoint and Network Detection Engineering, custom adversary emulation, and comprehensive Purple Team Capstones.

## Learning Path

### Path A: AWS Core Security Specialist
1. **Cloud Basics:** Start with [AWS Cloud Fundamentals for Cybersecurity Analysts](https://learn.secbyte.org/ctf/aws-cloud-fundamentals-for-cybersecurity-analysts).
2. **Identity & Access Controls:** Master policy enforcement via [AWS IAM Security](https://learn.secbyte.org/ctf/aws-iam-security-policies-privilege-boundaries-incident-resp).
3. **Infrastructure Isolation:** Hardened networks and compute using [AWS VPC Security](https://learn.secbyte.org/ctf/aws-vpc-security-design-observe-defend) and [AWS EC2 Security](https://learn.secbyte.org/ctf/aws-ec2-security-from-misconfiguration-to-defense).

### Path B: Detection Engineer & Purple Teamer
1. **Foundations:** Begin with [Threat-Informed Defense Foundations](https://learn.secbyte.org/ctf/threat-informed-defense-foundations).
2. **Rule Authoring:** Practice telemetry analysis via [Endpoint Detection Engineering](https://learn.secbyte.org/ctf/endpoint-detection-engineering) and [Network Detection Engineering Fundamentals](https://learn.secbyte.org/ctf/network-detection-engineering-fundamentals).
3. **Offensive Emulation:** Execute threat paths using [Custom Attack Scenarios](https://learn.secbyte.org/ctf/custom-attack-scenarios) and [Adversary Emulation Campaign](https://learn.secbyte.org/ctf/adversary-emulation-campaign).
4. **Purple Team Assessments:** Validate detection gap closure across [Enterprise Purple Team Assessment](https://learn.secbyte.org/ctf/enterprise-purple-team-assessment), [Purple Team Capstone](https://learn.secbyte.org/ctf/purple-team-capstone), and [Purple Team Final Challenge](https://learn.secbyte.org/ctf/purple-team-final-challenge).
